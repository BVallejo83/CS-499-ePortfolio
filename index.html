Algorithms and Data Structures Enhancement

This artifact showcases enhancements made to a vector-based sorting program developed in C++. The focus of this work was implementing and analyzing the selection sort algorithm while improving overall code structure and performance tracking.

The program uses a vector data structure to manage dynamic collections of data efficiently. Selection sort was implemented to organize the dataset by repeatedly identifying the smallest value in the unsorted portion and placing it in its correct position.

Enhancements included improving code readability, restructuring loops to eliminate redundancy, and incorporating execution time measurement using clock() to evaluate performance. Testing with multiple datasets confirmed correct functionality and provided insight into how the algorithm scales with larger inputs.
