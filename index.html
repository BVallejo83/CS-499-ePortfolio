Algorithms and Data Structures Artifact

This artifact represents my milestone two enhancement work in algorithms and data structures. The project focuses on improving a vector-based sorting program developed in C++. My enhancement concentrated on implementing and analyzing the selection sort algorithm while also improving code structure, readability, and performance tracking.

The program uses a vector data structure to store elements, which allows dynamic resizing and efficient indexed access. Selection sort was implemented to organize the data by repeatedly identifying the smallest value in the unsorted portion of the list and swapping it into the correct position. This project helped demonstrate how algorithm design directly affects efficiency and maintainability.

Enhancements included improving code readability, restructuring loops to reduce redundancy, and adding execution time measurement using clock() to evaluate performance. Testing was performed with multiple datasets to verify correctness and to analyze how the algorithm behaves as input sizes increase. This artifact demonstrates my ability to apply algorithm analysis, improve program structure, and connect performance results to software design decisions.
