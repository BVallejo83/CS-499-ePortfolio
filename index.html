Algorithms and Data Structures Enhancement

This artifact demonstrates enhancements made to a vector-based sorting program developed in C++. The project focuses on implementing and analyzing the selection sort algorithm while improving code structure and performance tracking.

The program uses a vector data structure to store elements, allowing dynamic resizing and efficient access to data. Selection sort was implemented to organize the elements by repeatedly identifying the smallest value in the unsorted portion of the list and swapping it into its correct position.

Enhancements included improving code readability, restructuring loops to reduce redundancy, and adding execution time measurement using clock() to evaluate performance. Testing was performed with multiple datasets to verify correctness and analyze how the algorithm behaves with larger inputs.
